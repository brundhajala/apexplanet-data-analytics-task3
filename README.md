# ApexPlanet Task 3 – Interactive Sales Dashboard

## Project Overview

This project is part of my Data Analytics Internship at ApexPlanet Software Pvt. Ltd.

Developed an interactive sales dashboard using Python, Streamlit, and Pandas to analyze sales data and present business insights through visualizations.

## Key Features

* Five KPI cards displaying important sales metrics.
* Interactive City, Category, and Customer Segment filters.
* Sales analysis through charts and graphs.
* Filtered sales data table.
* Dynamic dashboard updates based on selected filters.

## Technologies Used

* Python
* Streamlit
* Pandas
* Data Visualization

## Project Structure

* `task3_apexplanet_dashboard.py` – Main dashboard application.
* `requirements.txt` – Required Python libraries.
* `.gitignore` – Files excluded from Git tracking.

## How to Run the Project

1. Clone the repository.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
streamlit run task3_apexplanet_dashboard.py
```

4. Open the local URL displayed in your terminal.
